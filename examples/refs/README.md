# Reference conversions

Original mlatlas recreations of well-known ML architectures (the LLM-comparison and textbook
figures used as references). Each file rebuilds the *architecture* — a public fact — in mlatlas's
own print-first style; the source figures were used only to confirm parameters, never traced.

Build any one with `typst compile --root . examples/refs/<name>.typ`, or all via
`./tools/render-all.sh`.
